El repositorio incluye:

1. **Código fuente comentado** de todos los módulos del prototipo (captura, detección de pose, cálculo geométrico, lógica de aplicación, interfaz gráfica y registro en CSV).

3. **`requirements.txt`** con las dependencias de Python necesarias para ejecutar el prototipo y los scripts de análisis.
4. **Scripts de análisis de datos** utilizados en la fase de validación (Cap. 6): cálculo de MAE, precisión de conteo, latencia y generación de gráficos comparativos.
